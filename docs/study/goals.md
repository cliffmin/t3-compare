# Goals and non-goals

## Goals

1. **Portfolio clarity:** Make it obvious in under a minute what problem this fork studies,
   what Cliff decided, and what remains upstream T3 Code.
2. **Agentic engineering practice:** Treat comparison as a harness problem: shared prompts,
   native per-provider sessions, readiness/send guards, answer provenance, and (later)
   bounded decision gates such as feature-flagged Jev.
3. **Honest evidence:** Prefer specs, tests, receipts, and labeled demos over implied
   adoption, model rankings, or productivity claims.
4. **Reviewable process:** Keep AI-assisted implementation accountable via contracts,
   focused tests, and written review notes.

## Non-goals (current)

- Public product growth (stars, binaries, hosted SaaS) as a success metric for this phase.
- A model leaderboard, Arena, or “which LLM is best” product.
- Claiming production usage, measured gains, or multi-platform verification that has not
  been done.
- Replacing coding-agent LLMs with Jev (Jev is for bounded decisions inside a harness).

## Success signals for this study phase

- A stranger can paraphrase the wedge (coding-agent compare, not chat multi-model).
- Spec + tests + case study align with runtime behavior for the scoped feature.
- Open issues describe experiments with acceptance criteria, not archived changelog notes.
- Live-provider demo status is explicit ([demo.md](./demo.md)).
