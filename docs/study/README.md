# Study notes

T3 Compare is framed as an **agentic-engineering study project** built on an independent
[T3 Code](https://github.com/pingdotgg/t3code) fork. The public goal is to practice and show
harness design (contracts, decisions, provenance, review), not to claim product adoption.
